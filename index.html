Selected Projects

[Research Projects]

AgentGR: Semantic-aware Multi-agent Group Decision Simulator for Group Recommendation

Co-authors, Shihao Guo (Student 2nd Author)
arXiv Preprint, Intended for KDD 2027 (CCF-A) | Oct 2024 – Feb 2026 | Xidian ISET Lab

Proposed AgentGR, an LLM-driven multi-agent framework that simulates real-world group decision processes for group recommendation. Designed the interaction logic of "member agents expressing preferences – leader agents exerting influence – group agents aggregating decisions", implemented with AutoGen under both static workflow and dynamic dialogue strategies. Outperformed 8 group recommendation baselines on MafengwoS and Weeplaces, with HR and NDCG improved by at least 9.74%.

AgentCR: Cognitive and Semantic Enhanced Agentic Course Recommendation Framework

Shihao Guo (Student 1st Author)
Submitted to Chinese Journal of Computers (CCF-T1) | Oct 2024 – Feb 2026 | Xidian ISET Lab

Proposed AgentCR, a multi-agent framework jointly modeling learner preferences, cognitive states, and course semantics. Built five collaborating agents (recommendation decider, cognitive diagnostician, preference perceiver, course parser, and recommendation reflector) in a closed-loop workflow of "content parsing – profiling – recommendation – reflective calibration", with a dual-cache memory design gated by semantic control for asynchronous read/write. Outperformed 10 course recommendation baselines on MOOCCubeX and MOOCData, with Recall and NDCG improved by up to 31.84%.

SemiDis: Reliability-aware Semi-supervised Distillation with Adaptive Temperature

Shihao Guo
Research Assistant, AIMS Lab, HKUST-GZ | Dec 2025 – Jun 2026

Addressed the limitations of FixMatch's global fixed temperature that ignores sample-wise prediction reliability. Designed a reliability metric r(x) based on the tail variance of the teacher's non-maximal class probabilities, with a sample-wise dynamic temperature T(x) adaptively sharpening or smoothing pseudo-labels. Replaced hard labels + cross-entropy with soft pseudo-labels + KL divergence distillation, implemented on the USB framework with EMA statistics and DDP synchronization. Achieved 75.23% Top-1 accuracy on CIFAR-100 with 200 labels, surpassing FixMatch (70.74%) by 4.49 percentage points.

ToolRIFT: Retrieval-Invariant Decomposition Framework for LLM Tool Calling

Co-authors, Shihao Guo (Co-first Author)
Submitted to AAAI 2027 (CCF-A) | Dec 2025 – Jun 2026 | AIMS Lab, HKUST-GZ

Proposed ToolRIFT to prevent candidate noise from polluting argument generation as the tool pool grows, decomposing tool calling into retrieval, selection, instantiation, and verification. Decoupled tool selection from argument instantiation on a frozen Mistral-7B-Instruct-v0.2 with stage-specific, hot-swappable LoRA adapters, so that argument generation is conditioned only on the selected tool schema. On API-Bank, the wrong-argument rate and selection error rate dropped to 7.79% and 10.13%; achieved an overall score of 80.0 on ToolAlpaca.

RL-based Intelligent Image Cache Algorithm for On-device Scenarios

Shihao Guo
AI Algorithm Intern, Huawei 2012 Labs | Aug 2025 – Dec 2025

Modeled on-device cache decisions as a Markov decision process to overcome FIFO/LRU policies that rely only on access recency. Fused request-item features and cache-pool state with Self-Attention + Target-Attention into a DQN-based policy outputting binary cache actions, with priority-based eviction of low-value images. Built a cache simulation environment reproducing FIFO / LRU / LFU baselines for Hit and Recall evaluation. Improved hit rate from 20% to 40% in small-memory scenarios; the algorithm was adopted in the WPS HarmonyOS image cache module.

HarmonyOS Adaptation Automated Agent System: Multi-tool Orchestration + RAG

AI Algorithm Intern, Huawei 2012 Labs | Aug 2025 – Dec 2025

Built an agent-driven automation toolchain with a LangGraph workflow orchestrating downloading, compiling, testing, log parsing and error backtracking, and a RAG knowledge base distilling historical patches and error experiences into fix strategies iterated with failure feedback. Achieved a fully automated closed-loop for whl package adaptation and accumulated reusable HarmonyOS adaptation knowledge assets.
